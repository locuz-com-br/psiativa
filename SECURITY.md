# 🔒 Security Policy

Thank you for helping keep **PsiAtiva** and its users safe.  
We take security vulnerabilities seriously and appreciate responsible disclosure.

---

## 📌 Supported Versions

Only the latest version of the project is actively maintained and eligible for security fixes.

| Version | Supported |
|---|---|
| Latest (`main`) | ✅ Yes |
| Older releases | ❌ No |

---

## 🐛 Reporting a Vulnerability

If you believe you have found a security vulnerability, **please do not open a public GitHub issue**.

Instead, follow these steps:

1. **Email us privately** at `security@psiativa.com.br` with the subject line:  
   `[SECURITY] Brief description of the issue`

2. Include in your report:
   - A clear description of the vulnerability
   - Steps to reproduce the issue
   - Potential impact
   - Any suggested fix (optional but appreciated)

3. We will acknowledge your report within **48 hours** and aim to provide a resolution or mitigation plan within **7 days**.

---

## 🤝 Responsible Disclosure

We ask that you:

- Give us a reasonable time to investigate and fix the issue before any public disclosure
- Avoid accessing, modifying, or deleting data that is not your own
- Do not perform denial-of-service (DoS) attacks or social engineering

In return, we commit to:

- Treating your report with confidentiality
- Crediting you in any public disclosure (if you wish)
- Working with you to understand and resolve the issue quickly
